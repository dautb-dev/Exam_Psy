# Симулятор экзамена по психологии управления

Локальное статическое веб-приложение без сборки и внешних зависимостей. Каждая попытка выбирает 40 случайных вопросов из банка в 400 вопросов — по четыре из каждой лекции. Для каждого вопроса заранее заданы три тематически близких неверных варианта; порядок всех четырёх ответов перемешивается. Сразу после выбора показываются правильный ответ и объяснение.

В `Lectures\` лежат оригинальные PDF и их Markdown-конверсии, в `Questions\` — исходный PDF с вопросами. Банк и ответы, используемые приложением, находятся в `questions.js`.

## Запуск локально

Откройте `index.html` в браузере. Ссылки на страницы лекций в разборе ответов откроют Markdown-файлы из `Lectures\converted`.

## Публикация через GitHub Pages

1. Создайте репозиторий и загрузите содержимое этой папки в корень ветки `main`.
2. Откройте **Settings → Pages**.
3. В разделе сборки выберите **Deploy from a branch**, ветку `main` и папку `/(root)`, затем нажмите **Save**.
4. После завершения публикации GitHub покажет ссылку на сайт в разделе Pages.

Загружайте исходные материалы только если у вас есть право на их распространение. При публикации из корня репозитория ссылки в разборе ведут на Markdown-файлы в `Lectures/converted`.
